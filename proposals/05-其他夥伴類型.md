# 其他夥伴類型 · 提案變體

同一個服務，五種不同的說法。**核心不變：我補你缺的那塊，我不碰你賺錢的那塊。**

---

## 通用公式

每個提案照這個結構寫，換掉三格就成：

```
① 對方已經有什麼      →  （不要碰）
② 對方缺什麼          →  （你補這裡）
③ 對方多賺多少        →  （具體數字）
④ 對方要投入什麼      →  （盡量寫「零」）
⑤ 為什麼不會惹禍      →  （這條決定成交）
```

---

## A · 家庭醫生 / 私家醫務所（未售同類產品）

| | |
|---|---|
| **已有** | 糖尿病前期、初診斷、指標邊緣個案；轉介權；病人信任 |
| **缺** | 註冊營養師（公營轉介輪候長）；覆診之間的跟進；依從性數據 |
| **多賺** | 可自行提供服務並收費（$600–800/位/月），或純轉介不收費而換取病人依從性提升 |
| **投入** | 零 |
| **不惹禍** | 我們不涉藥物、不作診斷、有專業彌償險、報告不作臨床結論 |

**開場**：
> 「你同病人講飲食控制，講咗好多次。下次見佢係四個星期後。
> 嗰四個星期我幫你跟。每個月寫份報告返嚟，你覆診時就有嘢喺手。」

> ⚠️ **不可以付轉介佣金。** 香港醫務委員會《專業守則》禁止醫生因轉介
> 而收受利益。你可以提供的是：免費／優惠評估、報告回寄、互相轉介、
> 聯合講座。**一旦有錢流動，關係與合法性同時毀掉。**

## B · 社區藥房

| | |
|---|---|
| **已有** | 每日見到攞慢性病藥的街坊；地區信任；人流 |
| **缺** | 差異化（藥房之間只能鬥價）；客戶黏性；增值服務 |
| **多賺** | 服務加價收入；服務會員回頭買藥；藥房定位由「賣藥」升為「健康站」 |
| **投入** | 一張枱、一個時段（或純轉介，零投入） |
| **不惹禍** | 我們不在藥房銷售任何產品，只做諮詢與跟進 |

**開場**：
> 「你隔籬條街開多兩間藥房，你哋只可以鬥價。
> 但如果你係全區唯一一間有註冊營養師駐場嘅藥房，
> 咁就唔係同一場仗。」

**變體：駐場模式** — 營養師每週駐藥房半日，藥房抽場地費或按人頭分成。

## C · 視光師 / 足病診療師 / 物理治療師

| | |
|---|---|
| **已有** | 專科檢查中會發現代謝相關問題的病人 |
| **缺** | 發現問題之後的**轉介出路**（現在只能叫病人「去睇醫生」） |
| **多賺** | 可選擇自行提供或純轉介；提升專業完整度 |
| **投入** | 零 |
| **不惹禍** | 我們不作診斷，不越入其專業範圍 |

**開場**：
> 「你眼底檢查見到啲嘢，你叫病人去睇醫生。之後呢？
> 你冇再見過佢，都唔知佢有冇去。
> 如果有個地方可以轉介，而且每個月有報告返返嚟你度呢？」

**這一類最容易入手**——他們沒有競爭關係，而且「轉介無出路」是真實痛點。

## D · 保險經紀 / 保險公司

| | |
|---|---|
| **已有** | 客戶名單；每年續保接觸點；客戶關係維繫需求 |
| **缺** | 有實質價值的增值服務（現在只有送禮品、做講座） |
| **多賺** | 客戶留存率；轉介新客；長線理賠成本（對保險公司而言） |
| **投入** | 零至低（可由保險方買單作客戶福利） |
| **不惹禍** | 純服務，不涉醫療、不涉核保 |

**開場（對經紀）**：
> 「你一年見客戶一次，講續保。
> 如果你可以送佢一個真係用得著嘅健康服務，
> 你一年就有十二個接觸點，而且係佢會多謝你嗰種。」

**開場（對保險公司）**：
> 「慢性代謝疾病係長期理賠嘅主要來源。
> 我哋做嘅係生活習慣管理，唔涉醫療，
> 可以作為你哋客戶福利或者健康計劃嘅一部分。」

**規模最大、周期最長。** 不要當第一批客戶做，但值得在有 5–6 間診所案例之後啟動。

## E · 企業 / 人力資源

| | |
|---|---|
| **已有** | 員工健康計劃預算；ESG 與員工福利需求；場地 |
| **缺** | 有實質內容的健康項目（現在多數只做體檢與講座） |
| **付費** | 企業直接買單：講座 $8,000–15,000／場；員工計劃按人頭 |
| **投入** | 場地、時段 |
| **不惹禍** | 教育與營養服務，不涉醫療 |

**開場**：
> 「你哋每年做體檢，員工攞到份報告，睇唔明，放埋一邊。
> 我哋做嘅係體檢之後嗰部分。」

**現金流最快** — 企業講座可以即場收費，不需要等病人累積。
**建議：第一個月就開始接洽，用來養住現金流，同時建立案例。**

## F · 健身中心 / 私人教練

| | |
|---|---|
| **已有** | 會員；訓練專業；會員流失問題 |
| **缺** | 營養端（教練多數不是註冊營養師，講營養有專業風險） |
| **多賺** | 服務加價；會員留存 |
| **投入** | 零 |
| **不惹禍** | 由註冊營養師提供，教練不需要越界講營養 |

**開場**：
> 「你嘅教練係咪成日俾人問『我應該食咩』？
> 佢哋答，其實有專業風險。我哋有註冊營養師，
> 你嘅教練可以放心話『呢個我轉介俾專業嘅同事』。」

## 優先次序建議

| 順序 | 對象 | 理由 | 起動時間 |
|---|---|---|---|
| 1 | **已售產品的診所** | 見 [10](../docs/10-臨床渠道模式.md)，最直接、CAC 最低 | 4–8 週 |
| 2 | **企業講座** | 現金流最快，可即場收費 | 4–6 週 |
| 3 | **視光師 / 足病 / 物理治療** | 零競爭，痛點真實，最易答應 | 6–10 週 |
| 4 | **家庭醫生** | 質素最高，但門檻最高，要有案例先 | 3–6 個月 |
| 5 | **藥房** | 需要駐場，營運較重 | 3–6 個月 |
| 6 | **健身中心** | 客群偏年輕，非核心 | 6 個月+ |
| 7 | **保險** | 規模最大、周期最長，要有往績 | 9–12 個月 |

**首 90 天集中做第 1 同第 2 項。** 一條做病人、一條做現金流。
