# 月度報告範本（送回診所）

> **這是整套提案裡最重要的一份文件。**
> 診所是看報告決定的，不是看提案決定的。
> 帶去會面時要印彩色、釘裝好、用真實但去識別的內容填滿——空白範本沒有說服力。

**設計三原則**：
1. **只呈現，不判斷。** 記錄病人做了什麼、數據是什麼。診斷與結論留給執業者。
2. **絕不提用藥。** 一個字都不提。
3. **執業者 60 秒內要睇到重點。** 第一頁就是摘要，細節在後面。

## 為什麼這份報告能成交

| 設計 | 對執業者的作用 |
|---|---|
| 第 1 頁「需要你留意的三點」 | 他 60 秒就攞到覆診要用嘅嘢。這一頁單獨就值 $900 |
| 通篇不提用藥 | 直接回答他最大的顧慮，而且是用行動回答，不是用承諾 |
| 事件記錄寫明「已通報、時間、我方未作評估」 | 顯示你有制度、有記錄、知道自己的界線在哪 |
| 「給貴診所的提問」一節 | 把病人推回他那裡，證明你不是在搶病人 |
| 病人原話 | 他四個星期裡聽不到的東西，這裡有 |
| 記錄完整度、達成率 | 客觀的依從性數據，他從來沒有過 |
| 每一頁的免責標註 | 一份可以放進病人檔案而不會惹禍的文件 |

**帶去見面時，把第 1 頁同第 4 頁揭俾佢睇。** 這兩頁決定成交。
