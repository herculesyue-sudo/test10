# 協議草稿

> ⚠️ **草稿，非法律文件。** 使用前必須由香港執業律師審閱定稿。
> 以下為條款清單與要旨，目的是讓你和律師的溝通有起點，節省律師時間與費用。

---

## 一、試點協議（1 頁，見面當日可簽）

**設計目的：讓對方在 60 秒內看完並簽名。** 越短越易成交。

```
─────────────────────────────────────────────────────────
              代謝健康管理服務 · 試點協議
─────────────────────────────────────────────────────────

甲方（服務提供者）：____________ 有限公司
乙方（診所）：____________
日期：____________

1. 試點內容
   甲方為乙方轉介之最多 3 位病人，提供為期 2 個月之
   代謝健康管理服務（方案 B，含 CGM）。

2. 費用
   試點期完全免費，包括 CGM 感測器成本。
   乙方無需支付任何費用，亦無最低人數承諾。

3. 甲方的界線
   3.1 甲方不會就任何藥物、胰島素或其劑量提供意見。
   3.2 甲方不會作任何療效聲稱。
   3.3 甲方不會向乙方之病人推銷任何產品。
   3.4 一型糖尿病、正使用胰島素、已有併發症、懷孕或
       18 歲以下之個案，甲方不會自行處理，交由乙方判斷。

4. 報告
   甲方每月向乙方提供書面報告。報告只呈現記錄與數據，
   不構成診斷或臨床建議。

5. 個人資料
   病人資料按《個人資料（私隱）條例》處理，
   用途只限提供本服務及向乙方報告，
   不作促銷、不轉售、不轉移予第三方。

6. 終止
   任何一方可隨時以書面通知終止，無需理由，無違約金。

7. 保險
   甲方持有專業彌償保險，保單資料已提供乙方查閱。

甲方簽署：____________    乙方簽署：____________
─────────────────────────────────────────────────────────
```

## 二、正式服務協議（試點轉付費時使用）

### 應包含的條款

| # | 條款 | 要旨 |
|---|---|---|
| 1 | 定義 | 「服務」「病人」「報告」「不良事件」之定義 |
| 2 | 服務範圍 | 方案 A / B 內容，明確列出**不包括**什麼 |
| 3 | **專業界線** | 不涉藥物、不作診斷、不作療效聲稱、不作臨床決定。**這是整份合約最重要的一條** |
| 4 | **排除個案** | 一型糖尿病、胰島素使用者、已有併發症、懷孕哺乳、18 歲以下、精神科用藥者 → 甲方不自行處理 |
| 5 | 不良事件 | 定義、通報時限（建議：知悉後 4 小時內）、記錄保存、雙方責任 |
| 6 | 費用與付款 | 每位病人每月計費、按月後付、階梯定價、付款期 |
| 7 | **不競爭 / 不招攬** | 甲方不與乙方病人建立直接零售關係、不推銷產品、不誘使病人轉診 |
| 8 | 個人資料 | PDPO 合規、用途限制、保安、保留期、跨境限制、雙方角色 |
| 9 | 保密 | 雙向 |
| 10 | 保險 | 甲方維持專業彌償險及公眾責任險，保額下限，保單可查 |
| 11 | 責任限制 | 甲方責任上限、排除間接損失。**但不得排除因疏忽引致人身傷害之責任**（香港《管制免責條款條例》第71章下此類排除無效） |
| 12 | 知識產權 | 報告格式、方法屬甲方；病人資料屬病人 |
| 13 | 期限與終止 | 1 個月通知、即時終止情形、終止後資料處理 |
| 14 | 適用法律 | 香港法律，香港法院管轄 |

### 三條特別要求律師處理的

**1. 責任分配（最重要）**

> 服務由甲方提供，臨床判斷由乙方作出。
> 若病人因臨床決定而受損，責任應如何分配？
> 若病人因甲方之飲食建議而受損呢？

這條沒有標準答案，要按實際運作方式擬定。**不要用網上範本。**

**2. 明確不構成醫療服務**

> 協議須明文載明：本服務為營養及生活習慣管理服務，
> 並非醫療服務，不構成診斷、治療或醫療建議。

這一條同時保護你和對方。

**3. 個人資料的角色界定**

病人資料由乙方轉介、甲方處理、再回報乙方。
在 PDPO 下，誰是資料使用者？誰負責發出收集個人資料聲明？
**建議：由甲方在首次接觸病人時直接發出並取得同意**，路徑最清晰。

## 三、營養師合約要點

同樣重要——**你的合規承諾，靠這份合約落地。**

| # | 條款 | 要旨 |
|---|---|---|
| 1 | 資格 | 須為香港註冊營養師，維持註冊有效，變動即時通知 |
| 2 | **禁止事項** | 不得就藥物、胰島素、劑量提供任何意見；不得作診斷；不得作療效聲稱；不得建議停藥減藥 |
| 3 | **薪酬** | 按時薪或固定薪酬。**不得與產品銷售額或數量掛鈎**（見 [06](../docs/06-單位經濟與定價.md#一條不可妥協的治理規則)） |
| 4 | **拒絕權** | 營養師有權判斷某產品不適合某病人而不予建議，公司不得施壓。此權利明文寫入 |
| 5 | 轉介義務 | 遇排除個案或異常，須即時上報並轉回診所 |
| 6 | 記錄 | 每次諮詢須記錄；不良事件須依 SOP 記錄 |
| 7 | 專業保險 | 個人專業彌償險由誰承擔，須明確 |
| 8 | 保密與資料 | PDPO 合規 |

**第 3 和第 4 條是整個商業模式的合法性支點。**
沒有這兩條，「產品建議是專業判斷」這個說法就站不住——
監管機構、法院、以及對方的律師，都會把它看成一個包裝過的推銷結構。

## 四、病人端文件

見 [templates/](../templates/README.md)：

| 文件 | 用途 |
|---|---|
| 知情同意書 | 服務性質、不介入用藥、排除人群、風險披露 |
| 收集個人資料聲明（PICS） | PDPO 第16條及第VIA部 |
| 不良事件記錄表 | 每宗獨立一頁，永久保存 |

**額外一份（診所模式專用）：**

**「告知主診執業者確認書」**
> 病人簽署確認：已告知／將告知其主診執業者正在接受本服務，
> 並同意本公司向該執業者提供月度報告。

這一份在診所模式下特別重要，因為它把資訊流向寫清楚，
也是你「不搶病人」承諾的書面體現。

## 五、給律師的簡報（節省費用）

第一次見律師時，帶這份簡報去，可以省一半時間：

```
1. 業務模式
   我們向診所提供營養與數據服務。診所轉介其病人，
   我們的註冊營養師提供飲食管理與 CGM 數據整理，
   每月向診所提交報告。我們不銷售產品、不作醫療判斷。

2. 需要意見的四個問題
   (a) 此業務模式在香港是否需要任何牌照或註冊？
   (b) 《不良廣告（醫藥）條例》（第231章）對我們的
       對外宣傳（服務層面）有何限制？
   (c) 診所與我們之間的責任分配應如何擬定？
   (d) 在 PDPO 下，我們與診所各自的角色為何？
       收集個人資料聲明應由誰發出？

3. 需要起草／審閱的文件
   · 試點協議（1 頁）
   · 正式服務協議
   · 營養師合約
   · 病人知情同意書、PICS、告知主診執業者確認書

4. 背景（供參考，非委聘範圍）
   我們合作的部分診所在銷售一款草本口服滴飲產品。
   我們不參與該產品的銷售、進口或宣傳。
   如律師認為此背景對上述問題有影響，請一併指出。
```

**第 4 段要照講。** 隱瞞背景等於買一份用不上的法律意見。
