# 提案套裝

給合作夥伴用的實物。目標：**讓對方主動想同你合作。**

## 核心邏輯

大部分人上門找診所、藥房、企業，是去**要東西**的——要貨架、要轉介、要分成、要場地。
所以對方一見你就開防衛。

這套提案反過來：**你帶著一樣能增加對方現有收入、而且不拿走他任何東西的東西上門。**

```
① 對方已經有什麼   →  不要碰（產品毛利 100% 留給對方）
② 對方缺什麼       →  你補這裡（營養師、CGM、跟進、報告）
③ 對方多賺多少     →  具體數字（8 位病人 = 每月多 $4,800–6,400）
④ 對方要投入什麼   →  零（試點免費、按人頭、隨時可停）
⑤ 為何不會惹禍     →  不涉藥物、有保險、有記錄 ← 這條決定成交
```

第 ⑤ 條是大部分執業者真正在意、但不會直接問的。**先答它的人贏。**

## 使用次序

```
1. 印好樣本月度報告（彩色、釘裝、填滿真實但去識別的內容）
2. 印一頁提案
3. 帶埋：營養師註冊資料、保險保單首頁、試點協議
4. 約見面，跑 15 分鐘腳本
5. 唯一的 ask：「你揀邊三個病人？」
6. 每次見面後填記分表
7. 做滿 10 次，回頭看「他問的第一條問題」那一欄，改提案
```

## 三條不可以破的線

1. **提案裡不出現產品。** 一旦材料裡有產品宣傳，對方立刻把你歸類為「來賣貨的」，定位就崩了。
2. **不付轉介佣金給醫護人員。** 醫委會與中醫藥管理委員會的專業守則禁止。有錢流動，關係與合法性同時毀掉。
3. **不為任何單一客戶破例去推產品。** 一次破例，其他診所對你「不搶生意」的信任就沒了。
