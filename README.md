## 這套系統明確不做的四件事

| 不做 | 原因 |
|---|---|
| 任何繞過內地監管把貨送入境的安排（拆單、代購夾帶、找人帶關） | 《藥品管理法》第124條、《刑法》第142條之一妨害藥品管理罪、走私 |
| 小紅書／任何平台自動發帖推廣降糖或逆轉糖尿病功效 | 《廣告法》第17、18條；《互聯網廣告管理辦法》第8條；小紅書社區規範；香港《不良廣告（醫藥）條例》第231章 |
| 用一型糖尿病患者減胰島素的 CGM 記錄作行銷素材 | 安全風險（DKA）＋ 第231章禁止疾病治療聲稱 ＋ 兩地均禁止患者見證式廣告 |
| 引用「100% 臨床有效率」「重啟胰島素分泌」「擺脫藥物依賴」等供應商文案 | 《商品說明條例》第362章虛假商品說明（刑事罪行，最高罰 $500,000 及監禁 5 年） |

## 這套系統做什麼

把收入主體由「賣一支保健品」轉為 **「香港代謝健康管理服務」訂閱**：
CGM 配置 ＋ 註冊營養師／註冊中醫師諮詢 ＋ 飲食運動教練 ＋ 數據報告。
服務可以合法宣傳、可以做內容、可以訂閱、毛利更高、不受醫藥廣告條例封鎖；
產品只在服務內、由持牌專業人員按個別情況建議，不作大眾功效廣告。

詳見 [商業模式設計](docs/03-商業模式設計.md)。
