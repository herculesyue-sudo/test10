# test10 — 三勇者塔防 (Three Heroes Tower Defense)

A complete, single-file HTML5 tower defense game built around 三個 hero characters.

## How to play

Open `index.html` in any modern browser — no build step or server required.

- **劍士 Swordsman ($80)** — short range, very fast attacks
- **弓箭手 Archer ($120)** — long range sniper
- **法師 Mage ($160)** — splash damage that also slows enemies

Pick a hero, click a grass tile to place them, then press **開始下一波** to start each
of the 10 waves. Click a placed hero to upgrade (up to Lv.3) or sell. Enemies
(👹 goblins, 👻 ghosts, 🐗 orcs, and a final 🐲 dragon boss) follow the dirt path —
if they reach your castle 🏰 you lose lives. Survive all 10 waves to win.

Other controls: the **速度 x1/x2/x3** button toggles game speed; clearing a wave
grants bonus gold.
