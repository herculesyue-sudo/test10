# 03 · 商業模式設計

## 一、你原本的模式，和它為什麼跑不通

```
小紅書自動發帖（療效內容）→ 私訊查詢 → 場外成交 → 想辦法寄入內地
     ↑ 帳號被封          ↑ 平台違規      ↑ 廣告法       ↑ 刑事風險
```

四個環節，四個獨立的致命點。任何一環修好，其餘三環仍然會殺死這門生意。
而且這個模式還有一個商業上的問題：**你唯一的差異化是價格**（三五折入貨、外面九折），
一旦競爭者也拿到同樣折扣，你就什麼都不剩。

## 二、換一個結構：賣服務，產品是服務的一部分

```
公開內容（教育／生活／專業，零療效聲稱）
        ↓
免費價值物（代謝健康自測、飲食記錄工具）→ 留資
        ↓
低價入門服務（HK$680 代謝健康評估）
        ↓
核心訂閱：香港代謝健康管理計劃（月費制）
   ├─ CGM 配置與數據解讀
   ├─ 註冊營養師 1 對 1
   ├─ 註冊中醫師辨證（如適用）
   ├─ 飲食／運動教練 + 群組
   └─ 產品：由專業人員按個別情況建議，計入套餐或另購
        ↓
續訂 / 家庭方案 / 轉介
```

### 為什麼這個結構解決所有問題

| 問題 | 解法 |
|---|---|
| 第231章禁止疾病治療廣告 | 你賣的是**服務與教育**，宣傳的是「營養諮詢」「健康管理」「數據監測」——這些不是治療聲稱，可以合法宣傳 |
| 產品無註冊、不能講功效 | 產品不再是廣告主角。由持牌專業人員在**一對一諮詢**中按個別情況建議——這是專業意見，不是廣告 |
| 平台封號 | 內容不含療效聲稱、不做站外導流成交，帳號可以長期存活 |
| 只有價格差異 | 服務、數據、專業人員、社群 = 競爭者抄不走的護城河 |
| LTV 低、復購難 | 訂閱制天然解決；而且服務毛利遠高於轉售產品 |
| 產品責任風險 | 有專業人員把關、有知情同意、有不良事件記錄，風險可控可保 |

### 關鍵設計原則（不可妥協）

1. **持牌專業人員必須是真人、真牌照、真參與。**
   香港註冊營養師（可查 HKRD 名冊）、註冊中醫師（可查中醫藥管理委員會名冊）。
   不能是掛名。這是整個模式的合法性支點，也是它的價值所在。
2. **產品建議必須發生在一對一諮詢內，且必須可以說「不建議」。**
   如果每個人的建議都是同一套產品，那不是專業意見，是包裝過的廣告。
3. **所有使用者必須被要求告知其主診醫生。** 書面、記錄在案。
4. **絕不介入處方藥調整。** 任何減藥、減針的討論，一律轉回主診醫生。這條寫進 SOP 與員工守則。

## 三、三個產品層級

### Tier 0 · 免費（獲客）

- 「代謝健康自測」線上問卷（12 題，不作診斷，輸出生活習慣建議 + 建議何時求醫）
- 「香港外食升糖指南」PDF（茶餐廳／點心／快餐的實用選擇建議）
- 每週電子報

目的：留資、建立專業信任、餵養再營銷。

### Tier 1 · HK$680 一次性（篩選）

**代謝健康評估**：60 分鐘註冊營養師一對一 + 飲食記錄分析 + 個人化報告 + 一份行動計劃。

目的：把好奇者轉為付費者。付過一次錢的人，轉為訂閱的機率是免費用戶的 10 倍以上。
也是自然的合規閘門——在一對一環境裡，專業人員才能合法討論個別情況。

### Tier 2 · 訂閱（核心收入）

| 方案 | 月費 | 內容 |
|---|---|---|
| 基礎 | HK$1,280/月 | 營養師月度跟進 1 次、飲食記錄回饋、社群、電子報 |
| 標準 | HK$2,480/月 | 基礎 + CGM 一個感測器/月 + 數據解讀報告 + 每兩週跟進 |
| 深度 | HK$4,880/月 | 標準 + 每週跟進 + 註冊中醫師辨證 |

**產品不計入訂閱費，另行購買。** 原因是按供應商標示的用量計算，
每月產品開支可達四位數以上，捆綁進訂閱會令定價失控——
詳細測算與這個問題的嚴重性，見 [06 · 單位經濟](06-單位經濟與定價.md#二一個必須先核實的用量問題)。

詳細測算見 [06 · 單位經濟與定價](06-單位經濟與定價.md)。

## 四、市場選擇與進入順序

| 階段 | 市場 | 為什麼 |
|---|---|---|
| 第 1 階段（0–3 月） | **香港本地** | 你在這裡、專業人員在這裡、可面對面、法規你能掌握、CGM 供應成熟 |
| 第 2 階段（4–9 月） | **美國華人**（加州、紐約、德州） | 服務可遠程交付、DSHEA 路徑清晰、支付物流成熟、客單價承受力高 |
| 第 3 階段（10–18 月） | 台灣、英國／加拿大華人 | 內容可複用，需逐地做法規適配 |
| **暫緩** | 中國內地零售 | 見 [02 · 二](02-法規地圖.md#二中國內地--為什麼找方法寄入去這條路不存在)。可做的只有**非交易性品牌內容**與**合法的醫療旅遊接待**（客人自行來港消費），不寄貨、不在內地成交 |

### 關於內地市場，唯一可能的合法路徑

如果你長線一定要做內地，只有兩條路，都很慢：

- **路徑一**：供應商投入資源做保健食品備案／註冊（藍帽子），或走跨境電商清單。
  這是供應商的責任，不是你能繞過的。你可以做的是推動他們做，並談好屆時的獨家代理權。
- **路徑二**：把內地訪客當作**來港消費的客人**——他們自行來香港，在香港的持牌處所
  接受服務、自行購買、自行帶走（仍須遵守其入境物品規定）。這在法律上成立，
  但**不能在內地平台上以廣告形式招攬**，只能靠非商業性的品牌內容與口碑。

兩條路都不是「幫你諗個方法寄入去」。這一點沒有變通空間。

## 五、法律實體與保險

| 項目 | 建議 |
|---|---|
| 公司 | 香港有限公司；服務與產品分屬兩間或至少兩條業務線，隔離風險 |
| 專業人員 | 以合約聘用，明確其專業責任保險由誰承擔 |
| 保險 | 產品責任險（≥HK$10M）+ 專業彌償險（Professional Indemnity，覆蓋營養諮詢）+ 公眾責任險 |
| 客戶文件 | 服務條款、知情同意書、個人資料收集聲明、免責聲明（見 [templates/](../templates/)） |
| 退款政策 | 明確、書面、符合《商品說明條例》關於服務說明的要求 |
