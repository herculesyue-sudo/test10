# 10 · 臨床渠道模式（診所已在銷售 → 重新定位）

> 新資訊（2026-08）：香港已有多間診所在銷售此產品。
> 本頁處理這個事實對策略的影響，並取代 [08](08-獲客渠道最佳路線.md) 中
> 「把中醫診所當作轉介夥伴」的假設。

---

## 一、先分清楚兩件事

「診所賣緊」呢個事實，**證明咗一樣嘢，但證明唔到另一樣**。

| | |
|---|---|
| ✅ **證明咗** | 產品在香港有實際銷售渠道、有專業人員願意用、市場需求真實存在 |
| ✅ **證明咗** | 專業渠道（clinic channel）對呢隻產品行得通——呢個正正係 [08](08-獲客渠道最佳路線.md) 嘅結論 |
| ❌ **證明唔到** | 產品已完成中成藥註冊 |
| ❌ **證明唔到** | 你可以用同樣方式**做廣告** |

**最關鍵嘅一點**：我從來冇講過你唔可以喺香港賣呢隻嘢。
我講嘅係**你唔可以賣廣告話佢醫得好糖尿病**。

賣（sell）同賣廣告（advertise）喺香港係兩條唔同嘅法例：

| 行為 | 管制法例 | 診所做緊 | 你原本想做 |
|---|---|---|---|
| 專業人員喺診症中向自己病人配發 | 《中醫藥條例》第549章 + 專業守則 | ✅ | — |
| 零售銷售 | 第549章 / 第132章（視乎產品身份） | ✅ | ✅ |
| **向公眾宣傳可治療糖尿病** | **《不良廣告（醫藥）條例》第231章** | ❌ 佢哋冇做 | ❌ 你原本想做 |
| 誇大或虛假聲稱 | 《商品說明條例》第362章 | ❌ | ❌ |

**診所做緊嘅係第 1、2 行。你原本嘅計劃係第 3、4 行。**
所以「診所賣得，我點解賣唔得」呢條問題，答案係：**你賣得，但你唔可以照原本咁賣廣告。**

## 二、為什麼診所的法律位置和你不同

呢個唔對稱係真實嘅，值得你明白，因為佢決定咗你應該企喺邊個位置。

**註冊中醫師向自己嘅病人，在診症過程中，按辨證結果配發** —— 呢個係
**執業行為（practice）**，受《中醫藥條例》及專業守則規管，責任在該名註冊人身上。

**你向公眾推廣同銷售** —— 呢個係**商業行為（trade / advertising）**，
受第231章、第362章規管，冇任何執業豁免可以借用。

同一件產品、同一個病人，**因為行為性質唔同，適用嘅法例就完全唔同。**

> ⚠️ 此段須由執業律師確認具體條文及豁免範圍，特別是《中醫藥條例》
> 對註冊中醫師配發中藥的處理。但方向上的不對稱是確實存在的，
> 而它正好指出你應該站的位置。

**結論：你唔應該試圖模仿診所嘅做法去做零售廣告。
你應該站到診所旁邊，做佢哋做唔到嗰部分。**

## 三、策略衝突：診所是你的競爭者，還是你的客戶？

呢個係 [08](08-獲客渠道最佳路線.md) 需要修訂嘅地方。

08 建議「招募中醫診所做轉介夥伴」。但如果**呢啲診所已經賣緊同一隻產品**：

- 你叫佢轉介病人俾你 → 佢會諗：「咁我自己嘅產品毛利呢？」
- 你以零售價賣同一隻嘢 → **你係佢競爭者，唔係夥伴**
- 你入貨三五折、市面九折 → 你有價格優勢，但你會**直接打爛佢哋嘅生意**，
  而佢哋正正係你最想合作嗰班人

**呢個衝突必須解決，唔可以扮睇唔到。**

解決方法只有一個方向：**你唔賣產品俾佢哋嘅病人，你賣服務俾佢哋。**

## 四、建議模式：臨床服務層（Clinical Service Layer）

```
       診所（已有病人、已有產品、已有毛利）
                    ↓  病人
        ┌───────────────────────────┐
        │   你 = 服務層              │
        │   · 註冊營養師飲食管理      │
        │   · CGM 配置與數據解讀      │
        │   · 每月書面報告返診所      │
        │   · 病人日常跟進與依從性    │
        │   · 不良事件記錄            │
        └───────────────────────────┘
                    ↓  報告
       診所（保留產品毛利 + 診金 + 服務加價）
```

### 診所有咩、缺咩

| 診所已經有 | 診所冇（你補呢度） |
|---|---|
| 病人 | 註冊營養師 |
| 專業信任與轉介權 | CGM 硬件、配置、數據解讀 |
| 產品毛利 | 兩次覆診之間嘅日常跟進 |
| 診金 | 結構化書面報告 |
| 執業身份 | 不良事件記錄系統 |
| — | 依從性管理（病人有冇跟住做） |

### 為什麼這個模式比零售好得多

| 問題 | 零售模式 | 臨床服務層 |
|---|---|---|
| 第231章廣告限制 | 致命 | **基本上唔關你事**——你唔向公眾宣傳，你嘅客戶係診所 |
| 獲客成本 | HK$4,900／訂閱者 | **接近零**，診所直接交病人俾你 |
| 同診所嘅關係 | 競爭 | 合作，佢哋賺多咗 |
| 產品法律身份未明 | 你承擔 | 產品由診所配發，**責任在執業者，唔在你** |
| 需要囤貨 | 要 | **唔使**——你唔賣產品 |
| 病人安全把關 | 你冇醫護身份 | 有註冊執業者把關，結構上正確 |
| 可複製性 | 逐個客攞 | 逐間診所攞，一間 = 8–15 個病人 |

**最重要嗰行係「產品法律身份未明」嗰行。**
產品有冇 `HKC-` 註冊，呢個問題仍然存在，但喺呢個模式下，
**你唔係銷售者、唔係進口者、唔係廣告發布者**——你係一個提供營養與數據服務嘅公司。
你嘅法律曝險由「最前線」變成「幾乎冇」。

## 五、商業模式與定價

### 兩個方案

| | 方案 A · 基礎 | 方案 B · 含 CGM |
|---|---|---|
| 內容 | 註冊營養師每月 1 次跟進、飲食記錄分析、月度報告返診所 | A + CGM 感測器 1 個/月 + 數據解讀 |
| **你向診所收** | **HK$900**／病人／月 | **HK$1,600**／病人／月 |
| 你的成本 | 營養師 0.5h ($350) + 平台 ($50) = **$400** | + CGM ($400) = **$800** |
| **你的毛利** | **$500（56%）** | **$800（50%）** |
| 診所向病人收（建議） | HK$1,500 | HK$2,400 |
| **診所賺** | $600／月 **＋ 全部產品毛利** | $800／月 **＋ 全部產品毛利** |

**關鍵設計：產品毛利 100% 留俾診所，你一蚊都唔抽。**
呢個係令診所肯合作嘅原因，亦都令你唔會被視為「借診所賣自己嘅貨」。

### 規模與損益

| 診所數 | 每間病人數 | 總病人 | 月毛利（平均 $650） |
|---|---|---|---|
| 2 | 8 | 16 | $10,400 |
| 4 | 8 | 32 | $20,800 |
| **6** | **8** | **48** | **$31,200** |
| 10 | 10 | 100 | $65,000 |

精簡固定成本（首 6 個月唔請全職，你自己做營運，營養師純合約制）約 **HK$20,000／月**。

> **損益平衡 ≈ 4–5 間診所 / 約 32 個病人。**
> 對照 [06](06-單位經濟與定價.md) 純廣告路線需 48 個訂閱者、約 20 個月——
> **呢條路大約 4–6 個月，而且廣告費近乎零。**

### 一間診所值幾多

一間有 8 個病人嘅診所 = $5,200／月毛利 = **$62,400／年**。
你只需要成功簽 6 間。**呢個係一個你一個人跑得掂嘅數字。**

## 六、怎樣向診所提案

### 開場（15 分鐘，帶樣本報告去）

> 「我知道你哋已經有喺用呢個產品。
>
> 我唔係嚟賣產品俾你嘅病人——產品你繼續賣，毛利全部係你嘅，我一蚊都唔抽。
>
> 我做嘅係你冇時間做嗰部分：病人日常食咩、有冇跟住做、
> 兩次覆診之間發生咗咩事。我有註冊營養師同 CGM，
> 每個月寫一份報告返俾你，你覆診時就有嘢喺手。
>
> 你收病人幾多係你決定。我向你收 $900，其餘係你嘅。」

### 為什麼這個提案很難拒絕

1. **唔搶佢生意**——第一句就講清楚，即刻解除防衛
2. **佢賺多咗**——服務加價 + 產品毛利照舊
3. **佢冇成本風險**——按病人數計費，冇病人就冇支出
4. **佢病人依從性提升**——病人跟得住，產品用得耐，佢嘅產品復購率反而升
5. **有文件**——月度報告係佢診所質素嘅證明

### 試點條款（降低對方決策門檻）

- 首 3 個病人**免費**做 2 個月
- 唔收簽約費、唔要求最低量
- 隨時可以停
- 報告格式可按佢要求調整

### 目標與節奏

| 週 | 動作 |
|---|---|
| 1 | 列出已知在售診所（問你嘅供應商攞下游名單，或直接問客戶喺邊度買） |
| 2–3 | 準備樣本報告 + 一頁提案 + 服務協議草稿 |
| 4–7 | 每週見 3 間，目標接觸 12 間 |
| 8–10 | 3 間試點啟動（免費期） |
| 11–16 | 試點轉付費，目標 4–5 間 |
| 17–24 | 擴至 8–10 間 |

## 七、順手拿到的免費盡職調查

診所已經賣咗一段時間 = **佢哋手上有真實世界數據，而且係免費嘅。**

見面時順口問（唔好審問式，當交流）：

| 問題 | 你想知咩 |
|---|---|
| 「你哋用咗幾耐？大概幾多個病人？」 | 樣本規模 |
| 「有冇病人反映過低血糖？有冇試過要送院？」 | **不良事件——最重要嗰條** |
| 「有冇病人係打緊胰島素嘅？佢哋點？」 | 高危群組實況 |
| 「病人一般用幾耐會停？點解停？」 | 真實留存率（直接餵入 [06](06-單位經濟與定價.md) 模型） |
| 「一個月大概用幾多支？」 | **解答服用量三個版本嘅矛盾** |
| 「供應商有冇俾過檢測報告你？有冇 HKC 註冊編號？」 | 產品法律身份 |
| 「你哋點定價？」 | 市場真實價格，唔係「九折」個傳聞 |

**如果多間診所都話「有病人試過低血糖」——
呢個就係 [09](09-供應商檢測報告評估.md) 嗰條西藥摻雜問題嘅實質線索，
而且係你零成本攞到嘅。**

反過嚟，如果幾百個病人用咗兩三年、冇低血糖事件——
呢個係支持產品安全嘅實質證據，比任何宣傳單張都有力。

**兩個方向嘅答案都對你有價值。呢個係你今個月可以做、成本最低、
資訊回報最高嘅一件事。**

## 八、仍然不變的三件事

換咗模式，但呢三條線冇郁過：

1. **唔向公眾宣傳療效。** 第231章管嘅係廣告，唔理你係邊種商業模式。
   你嘅對外內容照跟 [04](04-內容與增長系統.md) 嘅合規框架。
2. **唔介入藥物調整。** 你嘅營養師唔可以、亦唔應該講減藥減針，
   即使係診所要求。呢條寫入服務協議。
3. **一型糖尿病、胰島素使用者、有併發症者** 仍然屬高關注群組。
   喺臨床服務層模式下佢哋有執業者把關，比零售好，
   但你嘅營養師仍然必須記錄、必須向診所反映異常。
