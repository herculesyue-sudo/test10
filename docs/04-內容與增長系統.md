# 04 · 內容與增長系統

## 一、渠道優先次序（按你的實際目標客群排）

香港糖尿病及糖尿病前期人群，主力年齡 45–70 歲，決策者常常是**子女（30–45 歲）**。
這決定了渠道排序——不是「哪個平台最紅」，是「你的人在哪」。

| 優先 | 渠道 | 角色 | 為什麼 |
|---|---|---|---|
| ⭐⭐⭐ | **Facebook + FB 群組** | 主力獲客 | 香港 45+ 人群密度最高；健康類群組活躍；廣告可精準投興趣＋年齡 |
| ⭐⭐⭐ | **WhatsApp**（Business API） | 私域經營、轉化、續訂 | 香港人真正在用的溝通工具；開信率遠高於 email |
| ⭐⭐ | **YouTube**（長片 8–15 分鐘） | 專業信任 | 營養師／中醫師出鏡；長尾搜尋流量；可嵌入官網 |
| ⭐⭐ | **Instagram + Threads** | 觸達子女輩 | 「幫爸媽搵方法」這個角色是高轉化決策者 |
| ⭐ | **官網 + SEO** | 承接與轉化 | 所有流量的落點；擁有自己的資產 |
| ⭐ | **小紅書** | 品牌曝光、海外華人 | **非交易性**用途，見下 |
| — | 線下 | 轉介 | 藥房、中醫診所、健身中心異業合作 |

**重點修正**：你原本把小紅書放第一。以你的客群與合規現實，它應該排第六，
而且用途完全不同。把資源錯配到小紅書，是這個計劃裡最大的機會成本。

## 二、四大內容支柱

每個支柱有明確的合規邊界。**支柱 1、2、4 是主力（佔 85%），支柱 3 佔 15% 且最克制。**

### 支柱 1 · 知識科普（40%）— 講病，不講產品

可以自由講糖尿病知識，因為你不是在推銷產品去治療它。
**紅線：同一篇內容裡，不得同時出現「疾病知識」與「產品」。** 一旦並置，即構成暗示性療效廣告。

主題方向：升糖指數、餐後血糖曲線、運動時機、睡眠與胰島素敏感度、
壓力荷爾蒙、CGM 讀圖入門、香港常見食物的實際影響、驗身報告怎麼看。

### 支柱 2 · 生活方式與飲食（30%）— 最安全、最實用、最易傳播

茶餐廳點餐指南、點心怎麼揀、飲茶食咩、外賣 App 選擇、
一星期備餐、糖尿病人的節日餐（年廿八、中秋、冬至）、街市買餸清單。

**這是你的流量引擎。** 香港人對「今日食咩」的興趣遠高於對機理的興趣，
而且這類內容完全沒有合規風險，可以放心放大投放。

### 支柱 3 · 專業人員內容（15%）— 建立信任，不作承諾

註冊營養師／註冊中醫師出鏡答問。
**紅線**：只答一般性問題，每條片加固定字卡「本內容為一般健康資訊，不構成醫療建議，
個別情況請諮詢您的醫生」。不回答「食咩可以降血糖」這類問題，改為
「血糖管理需要醫生評估，我可以講的是飲食結構的一般原則」。

### 支柱 4 · 服務與品牌（15%）— 這裡才賣嘢，而賣的是服務

CGM 開箱與配置過程、營養師諮詢實錄（經同意、去識別）、
服務流程介紹、客戶的**生活改變**（不是血糖數字）分享、團隊介紹。

**紅線**：客戶分享只講「食得健康咗」「知道自己食咩會升」「有人跟進安心咗」，
**絕不出現血糖數值、HbA1c、用藥量、CGM 對比圖。**

## 三、小紅書的真實可用邊界

不是不能用，是要改用途。**把它當品牌曝光渠道，不是成交渠道。**

| 可以做 | 不可以做 |
|---|---|
| 香港生活／飲食內容（茶餐廳、街市、點心） | 任何降糖、控糖、逆轉、調節血糖的字眼 |
| 一般營養知識（不指向疾病） | 產品出鏡、包裝、瓶身、價格 |
| 香港健康管理服務的**存在**（品牌介紹） | 引導私訊、留微信、「想了解私我」 |
| 專業人員的科普人設 | 前後對比圖、CGM 圖表、患者見證 |
| 引導至官網／小紅書店鋪（如已開通並合規） | 站外導流成交（平台明令違規，直接封號） |
| 單一帳號穩定運營 | **多帳號矩陣、群控、自動化批量發布** |

### 關於「自動發帖」

你想要的自動化，在小紅書上是最快被封的行為模式：
批量帳號 + 定時發布 + 相似內容 + 引流話術 = 風控系統的教科書特徵。

**可以自動化的是內容生產流程，不是發布行為本身：**

```
AI 生成草稿 → 合規詞庫掃描（自動）→ 人工審核 → 人工發布 → 數據回收（自動）
     ↑ 自動          ↑ 自動              ↑ 必須人      ↑ 必須人     ↑ 自動
```

工具見 [compliance/](../compliance/) 與 [05 · 自動化架構](05-私域轉化SOP.md#六可自動化與不可自動化的邊界)。

## 四、合規改寫對照表（直接抄用）

左邊是你手上材料的原話，右邊是可以發的版本。

| ✗ 不能發 | ✓ 可以發 |
|---|---|
| 「三個月血糖逆轉，HbA1c 降到 5.7 以下」 | 「三個月，佢由唔知自己食咩會升，到而家去到茶餐廳識得點餐」 |
| 「修復胰腺 β 細胞，重啟胰島素分泌」 | 「胰島素喺身體點運作？註冊營養師用 3 分鐘講清楚」 |
| 「多數患者 3 個月內減少降糖藥用量」 | 「用藥調整一定要由你嘅主診醫生決定，我哋做嘅係幫你記錄同準備好問醫生嘅資料」 |
| 「100% 臨床有效率」 | （刪除，無替代。任何有效率數字都不能出現） |
| 「天然草本，根源清毒素」 | 「天然草本成分，香港製造」（僅屬性描述，不含功效） |
| 「糖尿病患者必看！」 | 「成日聽人講飲食控制，實際點做？」 |
| 「想了解產品私我」 | 「完整指南喺我哋官網，profile 連結」 |
| CGM 前後對比圖 | CGM 開箱／點戴／讀圖教學（教育性，非效果展示） |

## 五、選題庫（48 條，可直接排期）

### A · 飲食實用（支柱 2，流量主力）

1. 茶餐廳早餐 8 個選擇，營養師點睇
2. 飲茶食點心：邊幾樣要小心
3. 車仔麵配料排行：湯底同配料嘅分別
4. 外賣 App 揀餐 5 個原則
5. 香港街市買餸一週清單
6. 白飯、糙米、意粉、米線邊個好啲？
7. 生果幾時食、食幾多
8. 冬至團年飯，一家人點食得舒服啲
9. 中秋月餅：想食嘅話點安排
10. 上班族午餐 10 分鐘備餐法
11. 港式奶茶／檸茶／凍飲的實際分別
12. 火鍋點食：湯底、蘸料、次序

### B · 知識科普（支柱 1）

13. 升糖指數（GI）同升糖負荷（GL）有咩分別
14. 點解食完飯想瞓？
15. 餐後散步 15 分鐘，身體發生咩事
16. 睡眠不足點樣影響代謝
17. 壓力荷爾蒙同血糖嘅關係
18. 空腹血糖、餐後血糖、HbA1c 分別代表咩
19. 驗身報告上嘅代謝指標點睇
20. 咩叫胰島素阻抗
21. 家族史：父母有糖尿病，我要點做
22. 一型同二型糖尿病嘅根本分別（**必發，用作教育與自我校準**）
23. 「糖尿病前期」係咩意思
24. 運動：帶氧定阻力訓練？

### C · CGM 與數據（支柱 1＋4）

25. CGM 係咩？點戴？痛唔痛？
26. 睇 CGM 圖表：三條線要識睇
27. 同一碗飯，5 個人 5 條唔同曲線
28. 進食次序（菜→肉→飯）點影響曲線
29. CGM 常見誤解 5 個
30. 邊啲人適合戴 CGM
31. 戴 CGM 之後改變咗嘅 3 個習慣
32. CGM 數據點樣幫你同醫生溝通

### D · 專業人員（支柱 3）

33. 註冊營養師答：最多人問嘅 5 條問題
34. 註冊中醫師講：中醫點睇「消渴」（歷史與概念，不作治療聲稱）
35. 營養師一日三餐食咩
36. 點揀營養師／點分辨資格
37. 「保健品」喺香港係點監管？（誠實講你自己的品類，建立信任）
38. 網上健康資訊點分真假

### E · 服務與品牌（支柱 4）

39. 我哋嘅代謝健康評估係做咩
40. 一次諮詢會傾啲咩（流程實錄）
41. 團隊介紹：邊個會跟進你
42. 點解我哋堅持要你同主診醫生講
43. 客戶故事：生活層面的改變（去旅行、返工精神、同屋企人食飯）
44. 常見問題：我哋唔會做嘅事（明講不介入用藥）

### F · 家人視角（觸達子女，高轉化）

45. 爸媽唔肯睇醫生，點算
46. 幫屋企人煮飯，最實用嘅 3 個調整
47. 陪長輩覆診前，準備咩資料
48. 送禮：唔好再送啲咩俾長輩

## 七、付費投放（僅香港 Meta 廣告）

| 項目 | 設定 |
|---|---|
| 目標 | 前 8 週：Lead（自測問卷留資）；之後：Purchase（Tier 1 評估） |
| 受眾 A | 香港，45–70，興趣：健康飲食、養生、健身、醫療 |
| 受眾 B | 香港，30–45，興趣：父母／長輩照顧、健康 |
| 再營銷 | 官網訪客 30 天、影片看足 50%、留資未購買 |
| 素材 | 支柱 2（飲食）表現最好，用作冷流量；支柱 3、4 用作再營銷 |
| 預算起步 | HK$300/日 × 30 日 = HK$9,000，測 6 組素材 |
| **廣告審核注意** | Meta 對健康類廣告有獨立政策：不得暗示受眾有某種健康狀況（「你有糖尿病嗎？」會被拒），不得用前後對比。文案用「想食得健康啲？」而非「血糖高？」 |
| 目標 CPL | HK$40–80／留資（香港健康類合理區間） |
