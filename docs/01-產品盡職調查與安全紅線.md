### 關於編號的關鍵判斷

香港真正的政府編號長這樣：

- 註冊藥劑製品：`HK-XXXXX`（藥劑業及毒藥管理局）
- 註冊中成藥：`HKC-XXXXX` 或過渡性 `HKP-XXXXX`（中醫藥管理委員會）
- 香港沒有「保健品註冊」制度，**不存在所謂「保健級認証批號」**

`HKR-TGHK001` 與 `HKR-P-000001` 均非上述任何一種。「優質國際產品—金獎」是商業獎項，
不是監管批准。**因此：不得在任何文案、包裝說明、客服話術中，把這些編號說成或暗示成
政府認證、註冊、批准、檢定合格。** 這樣做即構成《商品說明條例》下的虛假商品說明。

## 二、D0：西藥摻雜篩查（最高優先，先做這個）

### 為什麼

文件《3個月的真實記錄》記載：一位 **30 歲一型糖尿病** 患者使用產品約 3 個月後，
血糖波幅由 3.3–12 mmol/L 收窄至日間多數時間 4–8 mmol/L，**期間已減胰島素 2 度**，
並曾出現跌至 3.3 mmol/L 的低血糖片段。

一型糖尿病的病理是自身免疫破壞胰島 β 細胞，β 細胞已不存在。任何草本成分都不可能
「修復 β 細胞、重啟胰島素分泌」。所以要解釋這組數據，只有幾個可能：

1. 患者同時改變了飲食、運動、注射時間或 CGM 校準 —— 最良性的解釋；
2. 觀察期偏差（蜜月期殘餘、感染康復、CGM 感測器差異）；
3. **產品含未標示的西藥降糖成分。**

第 3 項在亞洲「天然降糖草本」品類中是有明確前科的高頻情況，最常見摻雜物為
**格列本脲（Glibenclamide／優降糖）** 與 **二甲雙胍（Metformin）**。
格列本脲的典型不良反應正正是**嚴重且持續的低血糖**——與記錄中 3.3 mmol/L 的片段吻合。

若屬第 3 項，後果是雙重的：
- **法律**：產品即屬未經註冊藥劑製品／假藥，在香港與內地銷售均為刑事罪行，不是行政罰款層級；
- **安全**：一型糖尿病人依賴一個成分不明的東西減針，若供應中斷、批次濃度波動或誤服，
  可直接走向**酮症酸中毒（DKA）**，屬可致命事件。

### 怎麼做

| 步驟 | 內容 |
|---|---|
| 送檢機構 | SGS 香港、Intertek 天祥、香港標準及檢定中心（STC）、香港生產力促進局 |
| 檢測項目 | ① 西藥摻雜篩查：磺胺尿素類（Glibenclamide, Gliclazide, Glimepiride）、雙胍類（Metformin）、格列奈類、噻唑烷二酮類、SGLT2i、DPP-4i<br>② 重金屬（鉛、砷、汞、鎘）<br>③ 微生物（總菌落、大腸桿菌、霉菌酵母）<br>④ 農藥殘留<br>⑤ 成分定性確認（牛黃真偽：天然／人工／體外培育） |
| 樣本 | **自行從市面或供應商處購買 3 個不同批號**，不要用供應商提供的「送檢樣本」 |
| 成本／時間 | 約 HK$8,000–20,000，2–3 週 |
| 判定 | 任何一項西藥檢出 → **立即停止整個項目**，並依《公眾衞生及市政條例》向衞生署通報，同時通知已使用的個案聯絡醫生 |

### 同時要做的臨床安全動作

無論檢測結果如何，對已在使用的個案（尤其那位一型患者）：

- 書面建議每一位使用者告知其主診醫生正在服用此產品，並提供完整成分表；
- **停止任何形式的減藥、減針建議**，包括「循序漸進式自行減少藥物用量」這句——
  文件《牛癀胺醣》與《核心資訊整理》都寫了類似指引，**這句必須從所有材料中刪除**。
  非醫護人員指導糖尿病人調整胰島素劑量，在香港可能觸及無牌行醫，在任何地方都是可致命的建議；
- 建立不良事件記錄表（見 [templates](../templates/)），低血糖事件必須記錄並跟進。

### D2 為什麼是最可能卡住的一關

《中醫藥條例》（第549章）下，一件產品若**同時**符合以下條件，即屬「中成藥」，必須註冊後方可銷售：

1. 成分完全或主要由中藥材組成 —— 牛黃、紅花均為附表2列明的中藥材；
2. 具有**診斷、治療、預防疾病**或**調節人體機能**的作用聲稱；
3. 屬製成品劑型（滴劑屬之）。

現行文案寫著「修復胰腺 β 細胞」「調節血糖血脂」「標本兼治」「100% 臨床有效率」，
第 2 項成立無疑。**若第 1 項亦成立而產品未持有 `HKC-` 註冊編號，則銷售、進口、
管有以作銷售用途，均屬《中醫藥條例》第119條罪行**（最高罰款 $100,000 及監禁 2 年）。

實務上有兩條出路，二選一：

- **出路 A（走註冊）**：由供應商申請中成藥註冊。時間以年計、需要穩定性測試與安全數據，
  但拿到 `HKC-` 之後，你就有一個真正可以說話的產品。
- **出路 B（走食品）**：徹底剝離所有疾病與機能聲稱，只作一般食品銷售，
  文案不得出現任何「降糖／調節血糖／改善胰島素／修復胰腺／併發症」字眼。
  本系統的內容與話術設計，即建立在出路 B 之上（見 [04](04-內容與增長系統.md)、[compliance/](../compliance/)）。

**你目前的實際狀態是：一個按出路 B 的法律身份（食品）銷售、卻按出路 A 的方式（藥品功效）宣傳的產品。
這是最高風險的組合。** 整套系統要做的第一件結構性修正，就是把宣傳拉回出路 B。

## 四、必須從所有材料中刪除的具體句子

以下句子直接來自你提供的產品文件，逐句都是可執法的違規點：

| 原句 | 問題 |
|---|---|
| 「以『根源清毒素、協同調代謝』機制實現 **100% 臨床有效率**」 | 虛假商品說明（第362章，刑事）；內地《廣告法》第16條禁止表示功效的斷言保證 |
| 「修復胰腺 β 細胞、**重啟胰島素分泌**」 | 疾病治療聲稱（第231章）；生理上對一型糖尿病不成立 |
| 「多數患者 3 個月內**減少降糖藥或降壓藥用量**」 | 誘導停藥／減藥，最高危一句 |
| 「讓患者有望**擺脫藥物依賴**、恢復健康」 | 同上 |
| 「HbA1c 有望降至 5.7 以下，**實現血糖逆轉**」 | 治療效果承諾 + 具體數值保證 |
| 「認証批號：HKR-TGHK001（**保健級**）」 | 暗示政府認證，香港無此制度 |
| 「已服降糖西藥患者……待血糖指標穩定下降後，**再逐步減量**」 | 非醫護給予處方藥調整指引 |
| 「經多年研發與**臨床驗證**」 | 無註冊試驗編號、無發表文獻支持 → 虛假商品說明 |
| 「**性功能明顯改善**（部分男性服用第一套即可感知）」 | 第231章附表就壯陽類聲稱另有嚴格限制 |
| 「特級供應品」「優質國際產品—金獎」「授權認証」等徽章 | 若非可查證的真實獎項與授權，即虛假商品說明 |

**執行動作**：把供應商提供的所有 PDF、圖卡、包裝說明列為「內部參考、不可外發」，
對外只使用本倉庫 [templates/](../templates/) 內經合規檢查的版本。
