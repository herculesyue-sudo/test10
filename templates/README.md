以下只是結構與必備條款的清單。

## 1 · 知情同意書（Tier 1 評估前必簽）

必備條款：

1. **服務性質**：本服務為營養及生活習慣管理服務，**並非醫療服務**，
   不構成診斷、治療或醫療建議，不能取代你的主診醫生。
2. **提供者資格**：服務由香港註冊營養師提供，姓名及註冊編號：＿＿＿＿。
3. **不介入用藥**：本服務**不會**就任何藥物、胰島素或其劑量提供建議。
   任何藥物調整必須由你的主診醫生決定。
4. **告知主診醫生**：你同意會告知主診醫生你正在接受本服務，
   並在使用任何補充品前提供完整成分表予醫生。
5. **產品性質**（如涉及）：本服務中可能提及的產品在香港的法律身份為**食品**，
   並非註冊藥物或註冊中成藥，不具治療疾病的聲稱，不可取代任何藥物。
6. **風險披露**：補充品可能與藥物產生交互作用；如出現低血糖、暈眩、
   視力突變等症狀，應立即求醫並通知我們。
7. **不適用人群**：一型糖尿病、正使用胰島素、已出現併發症、
   懷孕或哺乳、18 歲以下、正服用多種處方藥者，**本服務不適用**。
8. **個人資料**：見第 3 份文件。
9. **退款政策**：＿＿＿＿。
10. 簽署、日期、見證。

## 3 · 收集個人資料聲明（PICS）

必備內容（《個人資料（私隱）條例》第16條及第VIA部）：

1. 收集目的：提供服務、跟進、記錄保存、（如經同意）發送健康資訊及推廣。
2. 資料可能轉交的類別：受聘的註冊營養師／中醫師、支付服務商、
   （如適用）物流商。**不會為利益轉移予第三方作促銷用途。**
3. **健康資料屬敏感個人資料**，儲存方式、保留期限與銷毀安排。
4. 資料是否會轉移至境外，以及轉移目的地。
5. 查閱及更正權利，聯絡方式（姓名／職銜／地址／電郵）。
6. **直接促銷同意**：獨立一格，須客戶主動勾選或回覆確認，
   並說明可隨時免費退出的方法。**預先勾選不算同意。**
